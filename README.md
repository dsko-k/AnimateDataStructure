### A web application providing real-time animations for key data structure operations.

## $\color{#00ffff}{\Large\mathcal{SUPPORTED\ DATA\ STRUCTURES}}$

* <span style="font-size: 1.15em;">Binary Search Trees</span>
* <span style="font-size: 1.15em;">AVL Trees</span>
* <span style="font-size: 1.15em;">Red-Black Trees</span>
* <span style="font-size: 1.15em;">Min Heaps</span>
* <span style="font-size: 1.15em;">Max Heaps</span>

* <span style="font-size: 1.15em;">Insertion node</span>
* <span style="font-size: 1.15em;">Search node</span>
* <span style="font-size: 1.15em;">Deletion node (with leaf, a single child, and two children with successor replacement)</span>

<p style="font-size: 1.15em;">Animations of tree operations:</p>

* <span style="font-size: 1.15em;">Traversals</span>

## $\color{#8b5cf6}{\Large\mathcal{TRAVERSALS\ AND\ CONDITIONAL\ SEARCH}}$
<p style="font-size: 1.15em;">Animations of traversals with node highlighting:</p>

* <span style="font-size: 1.15em;">In-Order</span>
* <span style="font-size: 1.15em;">Pre-Order</span>
* <span style="font-size: 1.15em;">Post-Order</span>
* <span style="font-size: 1.15em;">Conditional traversals</span>

<p style="font-size: 1.15em;">Conditional traversals search for a node and terminate once the target value is located during traversal.</p>

## $\color{#ec4899}{\Large\mathcal{ANALYTICS\ AND\ UI}}$
<p style="font-size: 1.15em;">Animated tables show in real-time:</p>

* <span style="font-size: 1.15em;">State of the data structure</span>
* <span style="font-size: 1.15em;">Node states and properties</span>
* <span style="font-size: 1.15em;">Operation logs</span>
* <span style="font-size: 1.15em;">Data structure metrics</span>

<p style="font-size: 1.15em;">Tables have:</p>

* <span style="font-size: 1.15em;">Animated sorting</span>
* <span style="font-size: 1.15em;">Animated live search</span>
* <span style="font-size: 1.15em;">Animated real-time updates</span>

## $\color{#6366f1}{\Large\mathcal{STATE\ PERSISTENCE}}$
<p style="font-size: 1.15em;">Saving data structures to user accounts with history management to search, reopen, and resume operations on saved snapshots.</p>
